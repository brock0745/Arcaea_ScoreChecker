# Arcaea 理論値チェッカー

リズムゲーム **Arcaea** の「理論値」「PM」「99.5%以上」「EX+」といった達成状況を、曲ごとに記録・管理できる非公式ツールです。
ブラウザだけで動作し、インストール不要・登録不要で誰でもすぐに使えます。

**🔗 使ってみる**: https://brock0745.github.io/Arcaea_ScoreChecker/

## これは何？

Arcaeaには700曲以上の譜面があり、「どの曲をまだ理論値取ってないか」「PMまでは取ったけどEX+はまだか」といった進捗を頭の中だけで追うのはかなり大変です。
このツールは、各譜面の達成状況をタップひとつで記録し、全体の進捗を一覧・グラフで見られるようにしたものです。

## 主な機能

- **達成状況をワンタップで記録**: 理論値・99.5%以上・PM・EX+ の4段階をカードのタップだけで記録。再タップで状態を切り替えられます
- **進捗をグラフで確認**: 難易度ごとの達成率などを可視化
- **絞り込み検索**: 難易度（FTR/BYD/ETR/INS）・達成状況・任意のスコア（例: 9,800,000以上）を組み合わせて絞り込み可能
- **スプレッドシートと連携**: コミュニティで使われているスコア管理用シート（xlsx）や、独自形式のCSVからスコアを一括で取り込み・書き出しできます
- **オフラインでも使える**: 一度開けばネット接続なしでも起動・利用できます（PWA対応）
- **ジャケット非表示モード**: 著作権に配慮して、ジャケット画像を使わず色だけで識別する表示モードも用意しています
- **データは自分の端末だけに保存**: 記録したスコアや達成状況は、サーバーには送られずブラウザ内（端末のストレージ）だけに保存されます。他の人に見られる心配はありません

## 使い方

1. 上のURLを開く
2. 曲のカードをタップすると達成状況が切り替わります（未達成 → 理論値 → 99.5%以上 → PM → EX+ のように巡回）
3. 上部のフィルターで難易度や達成状況を絞り込めます
4. まとめてスコアを入力したい場合は、フッターから入力用CSVをダウンロードして編集→取り込みも可能です

スマホのホーム画面に追加すれば、アプリのように起動できます（ブラウザの「ホーム画面に追加」機能を使ってください）。

<details>
<summary>デプロイ方法（GitHub Pages）</summary>

1. このフォルダの中身をリポジトリのルート（またはお好きなサブフォルダ）にそのまま置いて push
2. リポジトリの Settings → Pages で公開ブランチを設定
3. `https://ユーザー名.github.io/リポジトリ名/` でアクセス可能になる

`index.html` は起動時に同じ階層の `songs.json` を `fetch()` で読み込みます。

<details>
<summary>曲データを追加する3つの方法</summary>

### 方法A: songs.json を直接編集（最も手軽）

```json
{"title":"英題","disp":"和題（なければ英題と同じでOK）","diff":"FTR","tier":0,"notes":1234,"cc":11.0,"jacket":null}
```

`tier` が不明な場合は `0` にすると「未確定」欄に表示されます。`jacket` はファイル名を指定しますが、`null` でもグラデーション表示で動作します。ファイル名には `? ! # & %` などURLで特別な意味を持つ記号を避けてください。

### 方法B: コンサルタントシート(xlsx)から一括更新

```bash
pip install openpyxl --break-system-packages
python3 update.py --xlsx "新しいコンサルタントシート.xlsx"
```

### 方法C: コマンドで1曲だけ追加

```bash
python3 update.py --add --title "曲名" --diff FTR --tier 25 --notes 1234 --cc 11.0
python3 update.py --set-tier --title "曲名" --diff FTR --tier 25
```

</details>

<details>
<summary>CSV機能</summary>

フッターの「入力用CSVを入手」で全譜面のCSVをダウンロードできます。スコア入力後に「CSVから取込」で一括反映できます。

```
曲名,難易度,レベル,スコア
Testify,BYD,12.0,10002221
Testify,FTR,10.9,
```

UTF-8 BOM付き、1行目はヘッダーです。

</details>

<details>
<summary>HTML版とアプリ版の違い</summary>

- **HTML版（ブラウザ / GitHub Pages）**: 最初に注意事項ページが表示され、スクロールするとトラッカー本体に切り替わります。
- **アプリ版（APK / WebView）**: 注意事項ページは表示されず、ツールバーの「注意事項」ボタンからモーダルで確認できます。

判定は URL のホスト名（`appassets.androidplatform.net` かどうか）で自動的に行われます。

</details>

<details>
<summary>データの保存場所について</summary>

達成マーク・スコア・アップロードした画像・追加した譜面は、すべて閲覧者の端末のブラウザ内（IndexedDB）に保存されます。`songs.json` やこのリポジトリには一切含まれないため、公開しても個人の記録が他人に見えることはありません。

</details>
